# vinho-verde-quality-prediction

A data science project analysing and predicting the quality of Vinho Verde wines using provided properties. Includes EDA, feature engineering, and machine learning models for classification and regression.

---

### Requirements

- **LaTeX** (e.g. MacTeX)
- `latexmk` (should come with most TeX distributions)
- `make`

## Generating the PDF Reports

Separate from the project submission, all latex files (e.g. for task notes, report drafts) can be found in /latex. 

* Docs are written in LaTeX and built using ```bash make latex.
* To empty bin/ after generation, run ```bash make empty.
* In the case that you, as examiner, do not have LaTex installed, PDFs have been pre-generated so you can view in docs/.
